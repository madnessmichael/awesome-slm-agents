# Taxonomy

Each entry has one primary category and optional cross-cutting tags.

| Category | Research question |
|---|---|
| Surveys and Perspectives | Why use small models in agents? |
| Agent Training and Distillation | Which agent capabilities should be learned? |
| Tool Use and Structured Actions | How do agents select tools and valid arguments? |
| Planning and Error Recovery | How do agents detect failure and resume progress? |
| Memory and Context Management | What belongs in weights, context, or external memory? |
| Multi-Agent Collaboration | When does communication justify its overhead? |
| Hybrid Systems and Routing | When should a small agent escalate? |
| On-Device and Edge Deployment | What can run locally under actual hardware limits? |
| Benchmarks and Evaluation | What is the cost of completing a task correctly? |

Empty categories are explicit editorial gaps, not evidence that no research exists. Reclassify through a documented PR; avoid duplicating entries across categories.
